   el chat).

   vía Management API (`database/query`) o Supabase CLI si el usuario lo
   prefiere.

   manual en `usuario` (`fuente='MANUAL'`) para no depender del sync real de
   RRHH en las pruebas locales.

   `src/modules/README.md`) + las rutas `app/(panel)/requerimientos/*` +
   `app/login/`.

   SKU real de los 725 → verlo en la bandeja de LOGISTICA.
8. Recién después de validar esto, seguir con el siguiente módulo (stock/
   aprobaciones, luego cotizaciones/compras, luego caja chica), aplicando el
   siguiente lote de migraciones cuando corresponda.
